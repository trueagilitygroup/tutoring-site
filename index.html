課程定位
POSITIONING

本課程為一對一家教式實作課程，目標不是培養傳統程式工程師，而是協助零基礎學習者在最長六個月內，建立足以申請初階資訊相關職務的背景、作品集、GitHub 專案紀錄與面試表達能力。

本課程聚焦於：建立資訊產品與數位專案工作的基本理解，培養需求分析、題目判斷、專案拆解與執行能力，並學會使用 AI 工具協作完成數位產品原型與 MVP。

適合對象
FOR WHOM
  • 無資訊、程式或軟體開發背景者
  • 非本科轉職者
  • 過去主要工作經驗不在科技業者
  • 對網站、Web App、數位產品與專案工作有興趣者
  • 希望在六個月內累積可求職的作品與背景者
核心能力
CORE SKILLS
  • 建立資訊產品與數位專案工作的基本理解
  • 培養需求分析、題目判斷、專案拆解與執行能力
  • 學會使用 AI 工具協作完成數位產品原型與 MVP
  • 建立 Trello 看板管理、版本迭代與測試觀念
  • 累積具真實場景價值的作品集
  • 完成履歷、作品集網站、GitHub 與面試準備
核心工具
TOOLKIT

本課程以學生可上手、可實作、可求職為原則，不以艱深程式理論為主，而是優先培養 AI 協作式數位產品開發與專案執行能力。

ChatGPT Discovery
需求釐清、題目發想、規格整理、文案優化、學習輔助
Claude Build
頁面生成、網站與 Web App 內容協作、文件整理
Gemini Prototype
原型設計、功能延伸、產品構想與協作
Trello Manage
任務視覺化管理與專案進度追蹤
Canva / Gamma Present
商用簡報、作品包裝與成果發表
NotebookLM Research
資料整理、知識整合與內容理解
GitHub Ship
專案版本管理與作品呈現

III
Portfolio Strategy · 作品集策略

避免一眼看出是學生練習題的專案

本課程最重要的設計原則之一，是讓作品具有真實場景價值。三件作品互相支撐，既展示產品思維，也展示執行能力與個人品牌。

主作品 A

保險客戶管理與追蹤 Web App

CRM · Web App · MVP

以學生過去保險業務背景為基礎，設計一個可管理客戶資料、需求紀錄、追蹤狀態、預約提醒與業務備忘錄的 Web App。

此作品的核心價值，在於展現學生能將過往專業領域轉化為資訊產品需求的能力，這正是面試時最具說服力的故事。

可展示能力 · Demonstrates
  • 真實場景需求分析
  • 使用者故事設計
  • 頁面規劃與資訊架構
  • 表單設計
  • 專案管理與版本迭代
  • 測試與問題回報
主作品 B

個人化保險 / 理財需求分析工具

Interactive Tool · MVP

設計一個輸入個人基本資訊後，能提供保障需求初步分析、風險分級與建議內容的互動工具。

與主作品 A 不同，這個專案的重點不在資料管理，而在商業邏輯與顧客場景理解，讓兩件作品互補、形成完整的能力光譜。

可展示能力 · Demonstrates
  • 商業邏輯與顧客場景理解
  • 表單與輸入流程設計
  • 結果頁資訊呈現
  • 內容架構設計
  • 使用者旅程與產品價值思考
支援作品 C

個人作品集網站

Personal Site · Live

建立一個整合個人背景、求職定位、技能工具、專案作品與聯絡方式的個人網站。

這是面試官第一眼會看到的東西，也是你個人品牌的對外門面。它要說的故事是：「這個人懂得如何介紹自己。」

可展示能力 · Demonstrates
  • 個人品牌包裝
  • 前端頁面設計
  • 資訊架構
  • 視覺與版面配置
  • 求職導向內容呈現

應避免的常見學生型題目 · Avoid these

  • Todo List
  • 學生選課系統
  • 一般記事本
  • 模仿教學網站的制式練習作品
